# Minecraft AI Build — Fabric 1.21.11

A starter server-side Fabric mod for permission-gated, paced construction from small JSON blueprints, with an optional OpenAI prompt-to-blueprint command.

## Status and scope

This is a **starter project**, not a compiled/release-tested mod. I cannot verify a successful Gradle build in this environment. The 1.21.11 Fabric toolchain versions below follow current Fabric examples and should be checked against the Fabric develop page if Gradle reports a version mismatch.

Implemented:
- Server-side `/aibuild` commands (no client mod required for the basic builder).
- Operator permission check (`permission level 2`) on all build commands.
- Slow construction at 1–5 blocks per server tick (default 1), plus pause/resume/stop/status.
- JSON blueprint loading and a built-in demo.
- Optional OpenAI prompt-to-blueprint generation using `OPENAI_API_KEY`.
- Size, coordinate, vanilla-block-ID, world-height, and world-border checks.

Not implemented yet:
- Native `.litematic`, Sponge `.schem`, or WorldEdit clipboard parsing. Litematica files use a specialized NBT format; this starter deliberately does not pretend JSON is a native Litematica schematic. The blueprint JSON format is a clean intermediate format for a future tested Litematica/Sponge adapter.
- Full player movement, tool use, inventory consumption, pathfinding, block-state properties, or protection-plugin integration. Server permissions here are a baseline; configure this only on a server where you have permission to build. Protection plugins may need a dedicated integration.
- A dedicated admin allowlist or region claim checks. Use only in a test world first and back up the world.

## Requirements

- Minecraft Java 1.21.11
- Fabric Loader and Fabric API for 1.21.11
- Java 21 JDK
- Gradle (or the Gradle wrapper generated by IntelliJ/Fabric template)
- IntelliJ IDEA Community or another Java IDE

## Build

1. Open this folder in IntelliJ IDEA as a Gradle project.
2. Let Gradle sync. If the wrapper is absent, install Gradle 9.2.1 or generate a wrapper in IntelliJ.
3. Run `gradle build` from the project folder.
4. The jar should be in `build/libs/` (choose the jar without `-sources` or `-dev` in its name).
5. Install that jar plus Fabric API into the **server's** `mods/` folder. Restart the server.
6. Start in a backed-up test world. Use an operator account.

## Commands

All commands require operator permission level 2.

- `/aibuild demo` — load the sample 7×7 starter-house blueprint.
- `/aibuild save-demo` — write `demo.json` to `<server directory>/ai-blueprints/`.
- `/aibuild load <name>` — load `<server directory>/ai-blueprints/<name>.json`.
- `/aibuild prompt <description>` — ask the OpenAI API to generate a small blueprint and load it.
- `/aibuild start` — start at the command user's feet + one block, one block per tick.
- `/aibuild start <blocksPerTick>` — choose 1–5 blocks per tick.
- `/aibuild pause`, `/aibuild resume`, `/aibuild stop`, `/aibuild status`.

At 20 ticks per second, 1 block/tick is approximately 20 blocks/second. Use `1` for the most cautious pace. A tick-rate setting is not a guarantee of human-like behavior and does not bypass server rules.

## OpenAI key

Set the key as an environment variable in the server launch environment; do not put it in source code or commit it.

macOS/Linux:
```bash
export OPENAI_API_KEY="your-key-here"
java -jar fabric-server-launch.jar nogui
```

Windows PowerShell:
```powershell
$env:OPENAI_API_KEY="your-key-here"
java -jar fabric-server-launch.jar nogui
```

For hosted servers, use the host's environment-variable/secret settings if available. The API is billed separately from ChatGPT. Do not share the key in chat or commit it to GitHub.

## Blueprint JSON format

Save as `ai-blueprints/tiny_house.json`:
```json
{
  "name": "Tiny House",
  "blocks": [
    {"x": 0, "y": 0, "z": 0, "block": "minecraft:stone"},
    {"x": 1, "y": 0, "z": 0, "block": "minecraft:oak_planks"}
  ]
}
```
Coordinates are relative to the player's build origin. Current validator allows +/-32 on each axis and up to 10,000 entries.

## Troubleshooting

- If Gradle can't resolve Loom/API versions, compare `gradle.properties` with https://fabricmc.net/develop/ and use the latest values for Minecraft 1.21.11.
- If the mod fails at startup, check `logs/latest.log` and confirm server Minecraft, Fabric Loader, Fabric API, and mod all match.
- If a protection mod denies changes, don't try to bypass it; use its normal admin/region permissions or disable the builder in that environment.
